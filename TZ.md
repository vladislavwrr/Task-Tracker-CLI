Трекер задач

Создайте приложение CLI для отслеживания ваших задач и управления списком дел.
Тренер задач - это проект, используемый для отслеживания и управления вашими задачами. В этой задаче вы создадите простой интерфейс командной строки (CLI), чтобы отслеживать, что вам нужно сделать, что вы сделали и над чем вы в настоящее время работаете. Этот проект поможет вам практиковать свои навыки программирования, в том числе работать с файловой системой, обрабатывать пользовательские входы и создавать простое приложение CLI.

Требования
Приложение должно работать из командной строки, принимать пользовательские действия и входные данные в качестве аргументов и хранить задачи в файле JSON. Пользователь должен иметь возможность:
    Добавляйте, обновляйте и удаляйте задачи
    Отметьте задачу как в процессе или сделанном
    Перечислите все задачи
    Перечислите все задачи, которые выполняются
    Перечислите все задачи, которые не выполнены
    Перечислите все задачи, которые находятся в процессе
Вот некоторые ограничения, которыми можно руководствоваться при осуществлении:
    Вы можете использовать любой язык программирования для создания этого проекта.
    Используйте позиционные аргументы в командной строке, чтобы принимать пользовательские входы.
    Используйте файл JSON для хранения задач в текущей директории.
    Файл JSON должен быть создан, если он не существует.
    Используйте собственный модуль файловой системы вашего языка программирования для взаимодействия с файлом JSON.
    Не используйте какие-либо внешние библиотеки или фреймворки для создания этого проекта.
    Убедитесь, что вы изящно справляетесь с ошибками и краю.

Пример
Список команд и их использование приведены ниже:
bash
# Adding a new task
task-cli add "Buy groceries"
# Output: Task added successfully (ID: 1)

# Updating and deleting tasks
task-cli update 1 "Buy groceries and cook dinner"
task-cli delete 1

# Marking a task as in progress or done
task-cli mark-in-progress 1
task-cli mark-done 1

# Listing all tasks
task-cli list

# Listing tasks by status
task-cli list done
task-cli list todo
task-cli list in-progress

Свойства Задач
Каждая задача должна обладать следующими свойствами:
    id: Уникальный идентификатор для задачи
    description: Краткое описание задачи
    status: Статус выполнения задачи (todo, in-progress, done)
    createdAt: Дата и время, когда была поставлена задача
    updatedAt: Дата и время, когда задача была обновлена в последний раз
Обязательно добавьте эти свойства в файл JSON при добавлении новой задачи и обновите их при обновлении задачи.
