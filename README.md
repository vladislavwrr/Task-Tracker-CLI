# Task Tracker CLI

Простой и легковесный интерфейс командной строки (CLI) для отслеживания и управления повседневными задачами.  
Проект реализован на чистом **Python** с использованием исключительно стандартной библиотеки (без внешних зависимостей) по спецификации [roadmap.sh/projects/task-tracker](https://roadmap.sh/projects/task-tracker).

---

## Возможности

* **Создание задач** с автоматической генерацией ID и фиксацией времени создания/обновления.
* **Редактирование описания** существующих задач.
* **Управление статусами**: `todo` (нужно сделать), `in-progress` (в процессе), `done` (выполнено).
* **Просмотр задач**: общий список или фильтрация по конкретному статусу.
* **Удаление задач** по их идентификатору.
* **Локальное хранение**: данные автоматически сохраняются в файл `tasks.json` в текущей директории.

---

## Требования и запуск

Для запуска требуется только установленный **Python 3.8+**.

1. Склонируйте или скачайте проект в рабочую папку.
2. Запустите команды напрямую через терминал:

```bash
python task_cli.py <команда> [аргументы]
```

---

## Примеры использования

### 1. Добавление задачи
```bash
python task_cli.py add "Купить продукты"
# Вывод: Task added successfully (ID: 1)
```

### 2. Обновление описания
```bash
python task_cli.py update 1 "Купить продукты и приготовить ужин"
# Вывод: Task 1 updated.
```

### 3. Изменение статуса задачи
```bash
# Перевести в статус "в процессе"
python task_cli.py mark-in-progress 1
# Вывод: Task 1 marked as in-progress.

# Отметить как выполненную
python task_cli.py mark-done 1
# Вывод: Task 1 marked as done.

# Вернуть в статус "к выполнению"
python task_cli.py mark-todo 1
# Вывод: Task 1 marked as todo.
```

### 4. Просмотр списка задач
```bash
# Показать все задачи
python task_cli.py list

# Фильтрация по статусу
python task_cli.py list todo
python task_cli.py list in-progress
python task_cli.py list done
```

### 5. Удаление задачи
```bash
python task_cli.py delete 1
# Вывод: Task 1 deleted.
```

## Структура проекта

* `task_cli.py` — точка входа в приложение, парсинг позиционных аргументов CLI и взаимодействие с пользователем.
* `file_handler.py` — модуль работы с файловой системой, валидации и CRUD-операций над JSON.
* `tasks.json` — локальный файл хранения задач (создаётся автоматически при первом запуске).
* `TZ.md` — техническое задание проекта.

---

## Структура данных задачи

Каждая задача сохраняется в следующем формате:
```json
{
  "id": 1,
  "description": "Купить продукты",
  "status": "todo",
  "createdAt": "2026-10-25T21:44:10.658018",
  "updatedAt": "2026-10-25T21:44:10.658018"
}
```
